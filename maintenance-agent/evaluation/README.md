# Evaluation — Maintenance Agent

Results are populated after running experiments. Do not invent scores.

## Structure

```
evaluation/
├── ml/          health_model_metrics.json  (classification report — auto-generated by health_model.py)
├── nlp/         ner_metrics.json, summarization_examples.json
└── rag/         retrieval_precision.json
```

## NLP Evaluation

Run `python -m nlp.evaluate_nlp` after labelling a test set in `data/ner_test_set.json`.

Metrics reported: entity precision / recall / F1, summarization quality (human-rated sample).

## RAG Evaluation

Run `python -m rag.evaluate_rag` on a manually labelled query set.

Metrics: Precision@3, qualitative grounding check.
